# 动态验收、返修与可复现交付

在制定验收和报告“通过”前阅读。数值、视觉、编辑器和目标引擎结果分别报告；按当前用户范围执行，不制造额外必需环境。

## 先固定标准和采样

记录目标动作、状态、分辨率、背景、比例、预算、失败条件、返修标准及度量单位。暂定门槛标为工程标准；不要把 R17 的 0.3 单位、95% 覆盖等数值复制成行业标准。小关节与大角色不一定用相同容差。

采样至少覆盖：标准姿势、所有目标动作、循环接缝、关键帧间插值、附件／alpha／层序边界前后，以及合理的额外关节扰动。单测烘焙 key 不能发现 key 之间的穿地或翻转。按失败所在时间段加密，再回归受影响动作，不为凑检查数量无限重跑。

| 检查 | 怎么取证 | 常见误判 |
|---|---|---|
| 格式与版本 | 用匹配的官方 Runtime 读取实际交付 JSON／二进制，保留版本和源码 hash | 自定义桥接 JSON 冒充官方 SkeletonJson，改版本字符串冒充兼容 |
| 引用与几何 | PNG／atlas／附件映射完整；数值有限、索引合法、UV 与权重适用 | region 没有蒙皮网格却报告“所有权重通过” |
| 刚性 | 世界空间边长与夹角，骨矩阵尺度／正交性；考虑合法镜像 | 单骨附件仍受父级非等比变换影响 |
| 连接与握持 | 关节锚点距离、握持点、相对旋转，结合实际画面 | 数学锚点重合，但画出的手没有抓住柄 |
| 隐藏区域与接缝 | 关节附近实际 alpha 覆盖，拉开／转动后看完整轮廓 | 一个圆盘被躯干遮住就判完整关节补全成功 |
| 可见穿地 | 真实 alpha 轮廓或合理的可见轮廓凸包；分离隐藏状态 | 用包含透明区的矩形顶点算穿地；把最低点防穿地当脚锁定 |
| 视角和遮挡 | 切换边界、层序、头身及装备正背的组合 | 用一张贴图变形解释所有朝向；alpha 遗失使隐身换位暴露 |
| 透明合成 | 解码、alpha 分布，白／黑／彩底实际查看，匹配渲染器预乘规则 | RGB 棋盘格当透明；统一收边／色键破坏有效细节 |
| UI 与离线 | 真实浏览器测播放、拖动、速度、动作、背景；无 JS／GL 错误；需要时测 `file://` 和请求记录 | 页面有文件就称运行通过；网页自带补偿掩盖导出数据缺陷 |
| 观感 | 同尺度联系图、慢速转向、极端姿势、真实 Runtime 连续帧 | IoU／PSNR 或程序零错误取代动画观感 |

矩阵或 C／JS 对照有价值时，分别运行对应官方实现，并记录浮点误差和输入 hash。不要把用同一套错误映射算出的两份结果当独立正确性证据。两个实现一致也不证明角色设计合理。

真实 Runtime 视频应从骨骼播放帧编码，解码确认可用并查看输出；标明查看了完整播放还是抽帧。生成服务直接返回的视频与骨骼动画交付不同。

## 返修判因

1. **装起来不像设计**：对照 PNG 长宽比、附件几何、父骨 scale／shear，再查整体头身比、肩宽和骨长。不先追加生图。
2. **抬手／抬腿裂开**：区分锚点错、完整部件缺失、重叠不足、层序错。局部延伸不能替代缺失的整块形体。
3. **武器穿手或打转**：检查闭手画法、握柄锚点、手与工具方向以及换手状态。
4. **某段突然飞走／消失**：查来源 alpha、附件、draw order、镜像和位置跳变；消失可能是原动作语义，不要把所有透明都判错误。
5. **边缘污染／实心装甲透底**：查真实 alpha 和色键反混色。确认材质实心后才归一近不透明区；保留原始生成和修正记录。
6. **转身跳切**：判断是否缺侧面状态或独立头身视角，而不是指望平滑骨曲线消除离散美术切换。

保留失败样本和修改前后条件。停止某条路线应依据明确的不兼容或成本门槛，不悄悄缩小成功标准；若任务仍要求批量实验，标明阶段工作与尚未完成的数量。

## 成本和证据

每个角色记录自动阶段耗时、生成／失败／重试次数、返修步骤、真实人工计时（有才填）、计费证据（有才填）、最终技术与美术状态。单次构建计时不代表端到端，更不是人工工时。

比较方法要固定或说明设计、模板、动作集、样本难度、预算和签收标准差异。不能把不同采样密度下的故障比例直接换算成改善百分比。解码成功率、技术通过率和生产合格率分别统计；原始生成、后处理变体、同角色返修不算不同角色。

每条重要结论标注：论文／官方支持、当前实测、工程假设、尚未验证。外部方法要核查输入输出、人工工序、代码、权重、许可及复现条件；未运行就称调研，不能称复现。

## 交付与独立重建

推荐保留的逻辑内容（目录可按项目调整）：

- 模板／语义映射、锚点、视角、来源及复用承诺。
- 原始请求、提交参考、响应和图片；处理后完整 PNG；失败迭代。
- 标准 Spine 数据、atlas／PNG、版本匹配的官方 Runtime 与许可记录。
- 交互预览、同尺度对照、动态样本、逐动作检查和未通过项。
- 无 API 调用的后处理／装配／导出／验证脚本，以及单独显式的生成入口。
- 成本、人工签收状态、文件 hash、环境版本和下一阶段判断。

为图集同高素材增加稳定次级排序键，避免目录枚举顺序改变布局。重建到临时目录后删除的是该临时副本的生成产物，不要删除源图和标定输入。重新处理原图、提取来源动作、构建附件和打包，比较关键输出；若编码器元数据导致字节不同，应报告原因与语义比较，不能谎报 hash 一致。

ZIP CRC 和 hash 只证明包完整；真正的重建验证证明依赖闭合。重新生图具有随机性和成本，不属于相同输入的确定性重放。对本机通过的结果只声称本机／该版本通过。

具备 Editor 时再报告其导入／保存／重开；只有 Runtime 测试时，`.spine` 工程验证仍为空。引擎测试按用户指定范围执行，缺环境应列缺项。公开发布或商业接入遵循当前任务授权，技能本身不授予这些权限。
